# Samuel Ribeiro — Imóveis de Alto Padrão

Website institucional e portfólio exclusivo de residências de alto padrão e luxo do corretor e consultor imobiliário **Samuel Ribeiro**.

## Destaques do Projeto
- **Design Quiet Luxury**: Estética refinada com paleta dark/warm gold, tipografia editorial (Cinzel & Cormorant Garamond).
- **Showcase de Residências**: Carrossel com navegação por chevrons, dados técnicos e valores oficiais em BRL.
- **Cinematic Experience**: Hero com transição fluida de vídeos em background, cards com preview dinâmico ao passar o cursor e modal cinematográfica para exibição dos episódios/tours do canal oficial.
- **Estatísticas Dinâmicas**: Contadores animados reativos a cada visualização em tela.
- **Integrações Oficiais**: Canal do YouTube [@SAMUELRIBEIROOFICIAL](https://www.youtube.com/@SAMUELRIBEIROOFICIAL) e contato direto via WhatsApp.

## Estrutura do Repositório
- `index.html`: Arquivo principal da aplicação web (código estruturado, estilização e interatividade em Javascript vanilla).
- `Resources/`: Mídias locais, logomarca oficial, fotos em alta resolução das residências e vídeos promocionais.
